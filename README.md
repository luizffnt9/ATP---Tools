# ATP---Tools
Line parameters are a key part of power system design. ATP/ATPDraw has several tools to calculate or input these parameters, like lumped, distributed, LCC, etc.
First off, the main goal here isn't to explain how these parameters are calculated. But if you prefer to calculate them yourself (or just want to see how it all works under the hood), you can use external code.
So, a Python code using the most accurate methods from the literature is available here. If Python isn't your favorite language, you can easily use an AI to adapt it (just remember to always double-check the results). The code was created by Professor Antonio Carlos Siqueira (UFRJ/COPPE).
